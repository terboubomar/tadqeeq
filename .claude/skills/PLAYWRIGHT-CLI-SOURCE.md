# playwright-cli skill

`.claude/skills/playwright-cli` is copied unchanged from https://github.com/microsoft/playwright-cli (commit b85c7a7,
Apache-2.0 licence in `playwright-cli/LICENSE`).

It drives a browser through the `playwright-cli` command, which is not a Tadqeeq dependency. Run it on demand
(`npx @playwright/cli ...`) instead of adding it to package.json. AGENTS.md comes first: no dependency changes, and no
screenshots or videos posted to GitHub (the skill's pr-attachments guide) unless the user asks.
