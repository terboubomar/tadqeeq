# Workflow skills from superpowers

The skill folders brainstorming, diagnosing-superpowers, dispatching-parallel-agents, executing-plans,
finishing-a-development-branch, receiving-code-review, requesting-code-review, subagent-driven-development,
systematic-debugging, test-driven-development, using-git-worktrees, using-superpowers, verification-before-completion,
writing-plans and writing-skills are copied unchanged from https://github.com/obra/superpowers (v7.0.2, commit 22f0b46,
MIT licence in SUPERPOWERS-LICENSE).

They are workflow guidance only. AGENTS.md and the user's instructions come first: work goes through a pull request and
the full CI gate before it reaches `main` (never a local merge into `main`), no force pushes or history rewrites, no
accounting-engine changes without asking, and only what the user asked for.
